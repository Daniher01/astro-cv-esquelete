Este proyecto implementa un servidor MCP (Model Context Protocol) especializado en análisis de datos de fútbol, diseñado para proporcionar capacidades avanzadas de scouting y evaluación de jugadores. El servidor integra el modelo estadístico DatAzul desarrollado internamente, ofreciendo análisis detallados de rendimiento de jugadores a través de múltiples métricas y algoritmos de clustering.

La aplicación utiliza FastMCP como framework base para la implementación del protocolo MCP, permitiendo una integración fluida con LLMs como Claude para generar recomendaciones automatizadas y análisis contextualizados. El sistema cuenta con 8 posiciones de fútbol configuradas, cada una con algoritmos de clustering específicos que agrupan jugadores según patrones de rendimiento similares, facilitando la identificación de perfiles tácticos y comparaciones estratégicas.

A través de este proyecto se exploran conceptos innovadores como la integración de IA con análisis deportivo, implementación de protocolos MCP para extensión de capacidades de LLMs, procesamiento avanzado de datos con Pandas, clustering de jugadores por características tácticas, y desarrollo de sistemas de recomendación automatizados para scouting deportivo profesional.
